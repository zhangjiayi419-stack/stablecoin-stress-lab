# Evidence audit — v0.4.0-evidence-audit

Author: Jiayi Zhang, University of Macau. Research software, not a peer-reviewed paper.

## Exact inputs and environment

Checkout tag `v0.4.0-evidence-audit`. Record `git rev-parse HEAD` with exported results.
The release is based on previously published source commit 0e67941. The release
manifest hashes source and data files independently of the eventual commit ID,
so it can be verified without a circular self-referential hash.

Reference replay environment: CPython 3.13, pinned transitive runtime dependencies
in `requirements-lock.txt`. Streamlit cloud may use another Python version; the
lock describes the tested local environment, not byte-identical hosted arithmetic.
Optional Chronos dependencies/model weights are not part of this runtime lock;
foundation scores are frozen artifacts and are not regenerated by these commands.

```
python3.13 -m venv .venv
.venv/bin/pip install -r requirements-lock.txt
.venv/bin/python verify_release.py
.venv/bin/python -m unittest discover -s tests -q
.venv/bin/python build_event_audit.py
.venv/bin/python -m streamlit run streamlit_app.py
```

`build_event_audit.py` uses only archived daily samples. `build_research_artifacts.py`
executes the longer original interval/covariate/response studies (requires scipy).
Avoid refreshing sources before reproducing archived scores. API recollection is a
new dataset version, not a replay. All model seeds are 419 unless an exported ABM
request explicitly specifies another seed; deterministic cohort runs expose their
full request, seed and SHA-256. Bootstrap: 100 moving-block resamples, block length 6h.

## Evidence and limitations

- SVB path fit is **in-sample**. It is not a calibrated structural ABM.
- Effective response holdout MAE 0.17945 pp versus zero-response 0.08342 pp:
  failed validation. The coefficients are not used to claim behavioral validity.
- Daily full-window GB skill +23.0% has 55 targets and only one stress target.
  GB stress MAE 497.07 bps exceeds persistence 445.04 bps.
- Hourly GB covariates improve GB MAE about 1.48%; both lose to persistence.
- New Terra/FTX/SVB daily audit uses identical rolling rules and scores only the
  named case window, after 120 pre-event days. This is retrospective, not
  preregistered or a guarantee of untouched event-level model selection.
- One empirical pool only. Non-SVB hourly covariates, multi-pool contract checks
  and externally validated structural ABM remain uncompleted.
- 346 empirical state records, 73 replay-catalog records and case-window subsets
  are different collections. Counts must be accompanied by unit, scope and clock.
- Stress label `abs(P_USD-1)>0.01` is a sampled two-sided market event, not issuer
  default. PD/LGD are formally defined in the UI but **not estimated**.

## State and thresholds

Pressure text derives from the active request, not a hard-coded 15% example.
Path and selected heatmap cell share an exact request fingerprint. Near-zero
heatmap cells use dark colors and numerical labels. The local pressure audit
executes current ±0.05/±0.10 pp independently and reports arbitrage and LP states.
Hourly threshold trading and finite capital can cause non-monotone model paths;
these must not be described as empirically identified liquidity cliffs.
